# E02-01: 現状の負荷のベースライン計測

親: [E02: パフォーマンス改善](../epics/E02-performance.md)

## 概要

改善前の PomOverlay の CPU 使用率・メモリ、それに合成を担う DWM(`dwm.exe`)の CPU 使用率を計測し、E02-02・E02-03 の効果を比べる基準にする。

## 完了条件

- 繰り返し使える計測スクリプトがリポジトリにある
- 改善前の数値がこのファイルに記録されている

## 依存関係

なし

## 設計の決定

- 計測スクリプトは `tools/measure.ps1`。起動前の DWM を20秒 → PomOverlay を起動して10秒待つ → 30秒計測 → 終了、の順に行う
- CPU は WMI の `Win32_PerfRawData_PerfProc_Process` から「1コア = 100%」換算で出す。`dwm.exe` は保護プロセスで `Process.TotalProcessorTime` が0になってしまうため(最初の試行で気づいた)。WMI のクラス名は日本語環境でもローカライズされない
- GPU は `Win32_PerfFormattedData_GPUPerformanceCounters_GPUEngine` の 3D エンジン使用率を1秒ごとにサンプリングした平均
- レイヤードウィンドウは DWM 側の合成コストにも効くので、PomOverlay だけでなく DWM も計測対象にした
- 計測は Release ビルド・既定の `config.json`・起動直後の状態(デバッグ表示はスクリーン1だけ ON)で行う

## 検証結果

2026-09-29 計測。環境:i7-10700K(16論理コア)/ RTX 2070 SUPER / モニター2台(3440x1440・1920x1080)

| 項目 | 1回目 | 2回目 |
|------|------:|------:|
| PomOverlay CPU(1コア換算) | 58.5% | 49.4% |
| PomOverlay GPU(3D) | 28.7% | 28.4% |
| DWM CPU 起動前 | 2.7% | 3.1% |
| DWM CPU 起動中 | 22.5% | 23.4% |
| DWM GPU(3D)起動中 | 11.9% | 12.1% |
| PomOverlay WorkingSet / Private | 198 MB / 461 MB | 198 MB / 469 MB |

- まとめると、縁を光らせるだけで PomOverlay が約0.5コア、DWM が約0.2コア、GPU が合計約40%を使っている。常駐ツールとしては明らかに重い
- 全体比に直すと PomOverlay の CPU は約3〜4%(タスクマネージャーで見える値)

## 未検証のまま残したこと

- 内訳(全画面レイヤードウィンドウの転送と `BlurEffect` のどちらがどれだけ効いているか)は切り分けていない。E02-02 の後にもう一度計測すれば、帯化の効果が分かる
- デバッグ表示 ON/OFF の差は計測していない
- 計測時間は30秒×2回。フェード中(モード切り替えの前後30秒)の負荷は見ていない
