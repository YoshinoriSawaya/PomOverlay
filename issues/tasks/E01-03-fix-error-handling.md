# E01-03: Updateループのエラーハンドリング見直し

親: [E01: コード整理とテスト基盤の導入](../epics/E01-code-cleanup.md)

## 概要

`MainWindow.Update`の`catch`は現状ログを吐くだけで処理を継続しており、同一原因で例外が16msごとに発生し続けると`error.log`が無限に肥大化する。連続失敗を検知してタイマーを止める、またはログを間引く処置を入れる。

## 完了条件

- 同一箇所で一定回数(仮：連続10回など)例外が発生した場合に、タイマーを停止するかログ出力を間引く
- 通常時の例外ログ機能(`DebugManager.LogError`)自体は維持する

## 依存関係

E01-01と並行して進めて良い(ロジック層の分離とは独立)。
