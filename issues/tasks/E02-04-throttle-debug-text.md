# E02-04: デバッグ表示の更新を間引く

親: [E02: パフォーマンス改善](../epics/E02-performance.md)

## 概要

デバッグ表示は毎フレーム(16msごと)大きなテキストを組み直していて、それだけで約17%(1コア換算)を使っている。初期状態でスクリーン1に出ているので影響が大きい。テキストの更新を1秒に数回に減らす。

## 完了条件

- デバッグ表示のテキスト更新が毎フレームではなくなっている
- `tools/measure.ps1` で、デバッグ表示ありの負荷が下がっていることを確かめる
