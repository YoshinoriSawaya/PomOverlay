# E02-02: ウィンドウを画面の縁の帯だけにする

親: [E02: パフォーマンス改善](../epics/E02-performance.md)

## 概要

今は各モニターに全画面サイズのレイヤードウィンドウを置いている。`AllowsTransparency` はソフトウェア描画になるため、縁しか光らせていなくても画面全体を毎フレーム転送している。`Modes` 内の `BlurMax`/`Thick` の最大値から逆算した幅の帯だけをウィンドウにする。帯幅は設定の変更時にだけ計算し直す。

## 完了条件

- 各モニターのオーバーレイが、縁の帯だけのウィンドウで構成されている
- 見た目が今と大きく変わらない(手動確認)
- E02-01 の手順で計測して、改善前より負荷が下がっている
