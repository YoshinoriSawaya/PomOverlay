# E01-05: コメントアウトされた旧実装の削除

親: [E01: コード整理とテスト基盤の導入](../epics/E01-code-cleanup.md)

## 概要

`MainWindow.xaml.cs`を中心に、置き換え済みの旧実装がコメントアウトされたまま大量に残っている(`CalculatePomodoroState`・`UpdateDebugText`の旧バージョンなど)。変更履歴はGitに残っているため、ソースからは削除する。

## 完了条件

- コメントアウトされた旧実装ブロックが削除されている
- 「修正後」のようなその場しのぎのコメントが整理されている

## 依存関係

E01-01(ロジック層分離)とあわせて行うと二度手間にならない。

## 設計の決定

- 対象は本体の全 `.cs`。コメントアウトされた旧実装のほかに、使われていないもの(`MainWindow._spinnerFrames`、`using static System.Windows.Forms.AxHost` など不要な using、`ScreenIndex` の二重代入)も削除した
- 「追加」「修正後」「【新設】」「ここがポイント」のような、変更したときの経緯を書いたコメントは、コードの意図を説明する文に書き換えるか削除した
- 実装と食い違っていたコメントは直した(FPS 表示の更新間隔「0.5秒ごと」→ 実装どおり1秒、トレイの「アイコンやテキストを切り替える」→ アイコンの切り替えはコメントアウトされていたのでテキストのみ、`ApplyVisuals` の「最後の Stop は最初の色を目指す」→ そういう処理は無いので削除)
- 挙動は変えていない
- `ScheduleItem.ApplyMode` の「文字列で保存される」というコメントは、正しいかどうか確かめていないので残した(E01-04 の未検証項目を参照)

## 検証結果

- 2026-09-29: ビルド成功・テスト46件すべて成功。行末が `;`・`{`・`}` のコメント行(コメントアウトされたコード)が残っていないことを grep で確認した

## 未検証のまま残したこと

- アプリを起動しての確認はしていない(コメントと未使用コードの削除だけなので影響は無い想定)

## ステータス

完了(2026-09-29)
