# E03: 設定ウィンドウ

## 概要

今は `config.json` を手で編集するしかない。GUI で設定を編集し、「適用」ですぐオーバーレイに反映できる画面を作る。

## 子タスク

- [x] [E03-01: 設定画面の ViewModel](../tasks/E03-01-settings-viewmodel.md)
- [x] [E03-02: 設定ウィンドウとトレイメニュー](../tasks/E03-02-settings-window.md)

## 完了条件

- トレイメニューの「設定...」から設定ウィンドウを開ける
- モードごとの時間・太さ・ぼかし・不透明度・明滅の周期・流れの周期・色、スケジュール、`TransitionSec`、`Fps` を編集できる
- 「適用」で `config.json` に保存され、すぐオーバーレイに反映される
- 不正な値は適用前に知らせ、適用しない(`ConfigValidator` を再利用)
