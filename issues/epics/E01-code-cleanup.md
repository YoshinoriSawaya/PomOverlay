# E01: コード整理とテスト基盤の導入

## 概要

`MainWindow` に集中している状態計算・物理演算のロジックをWPF非依存のクラスへ分離し、ユニットテストを書けるようにする。
あわせて、エラーハンドリングと設定値バリデーションの課題、コメントアウトされた旧実装の削除も行う。

## 完了条件

- `PomodoroStateCalculator`・`AuroraPhysicsCalculator`(仮称)がWPFに依存せず、`MainWindow`から呼び出される形になっている
- 上記ロジックに対するユニットテストが存在し、`dotnet test` で実行できる
- Updateループで同一原因の例外が連続しても、ログが無限に肥大化しない
- 不正な`config.json`値(0以下のPulseSec等)でクラッシュ・ゼロ除算が起きない
- 旧実装のコメントアウトがソースから削除されている
