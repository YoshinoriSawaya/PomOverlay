# PomOverlay

ポモドーロテクニックをサポートする、画面の縁（フチ）の色が変わるC#製オーバーレイタイマーです。

## 📝 概要 (About)

集中状態（フロー）を途切れさせないことを目的としたポモドーロタイマーです。
画面の中央にポップアップや数字を表示するのではなく、**画面の境界線の色を変化させる**ことで、視界の端で自然に時間経過と休憩のタイミングを知らせます。

イラスト制作やプログラミングなど、作業領域を広く使いつつ、作業の邪魔をされずに時間管理をしたい方に最適です。

## ✨ 主な機能 (Features)

- 画面の縁（フチ）への控えめなカラーオーバーレイ表示(グラデーション + ぼかしで「オーロラ」のように明滅する)
- ポモドーロのサイクル（Focus / Rest / Sleep）に応じた色・ぼかし・脈動速度の変化
- 時間帯によるモードの強制切り替え(スケジュール機能。例：00:00-06:00はSleepモード)
- トレイメニューからのモード強制切り替え・言語切替(JP/EN)・デバッグ表示
- 作業の妨げにならないクリックスルー（マウス操作の透過）対応
- マルチモニター対応(全モニターにオーバーレイウィンドウを配置)

## 🛠 技術スタック (Tech Stack)

- **言語:** C# / WPF
- **対象フレームワーク:** `net10.0-windows`
- **IDE:** Visual Studio 2022 (`PomOverlay.slnx`)

## 🚀 使い方 (Usage)

1. [Releases](https://github.com/YoshinoriSawaya/PomOverlay/releases) ページから最新の実行ファイルをダウンロードするか、後述のローカル開発環境でビルドします。
2. `PomOverlay.exe` を起動します。初回起動時は同じフォルダに `config.json` が自動生成されます。
3. 起動すると、各モニターの縁に、現在のモード(初期状態ではFocus/Restの25分/5分サイクル)に応じたオーバーレイが表示されます。
4. トレイアイコンの右クリックメニューから、モードの強制固定・設定ウィンドウ・設定ファイルを開く・言語切替・デバッグ表示のON/OFFができます。

## ⚙️ 設定 (`config.json`)

トレイメニューの「設定...」で開く設定ウィンドウから編集し、「適用」ですぐ反映できます。「設定ファイル (JSON) を開く」から直接編集することもできます。主な項目：

- `Modes`：`Focus` / `Rest` / `Sleep` ごとの時間・線の太さ・ぼかし範囲・脈動周期・色
- `Schedules`：時間帯によるモード強制(開始/終了時刻とモード)
- `TransitionSec`：モード切り替え時のフェード時間(秒)
- `Fps`：1秒あたりの更新回数(既定30、1〜60)。負荷はほぼこれに比例する
- `OverrideMode`：手動でのモード固定(通常は`Auto`)。モード名は `"Focus"` のように名前で書く(古い数値形式も読める)

読み込み時(起動・リロード)に値をチェックし、0以下の`PulseSec`、負の`Min`、読めない色名などの不正な値は安全な値に補正して、補正内容をダイアログで表示します。`config.json`自体は書き換えません。

## 💻 ローカル開発環境の構築 (Getting Started)

1. リポジトリをクローンします。

```
git clone https://github.com/YoshinoriSawaya/PomOverlay.git
```

2. リポジトリのルートにある `PomOverlay.slnx` を Visual Studio 2022 で開きます。
3. `F5` キーを押してビルドおよびデバッグを実行します。

開発時の詳しい手順・注意点は [`docs/development.md`](docs/development.md) を参照してください。設計の全体像は [`docs/architecture.md`](docs/architecture.md) にまとめています。
